# Gchess cosmetic collection

The catalog in games/cosmetic_catalog.py is authoritative. All current options remain free; there are no payments, wallets, reward grants or VIP entitlements. Six catalog categories offer 20 options each: avatars, boards, piece styles, headwear, clothing and hairstyles. Accessories offer 25 choices across beard/moustache, eyewear and earrings (including empty choices).

Each account has independent slots. Equipping a beard replaces only the current beard; lenses, earrings, hairstyle, headwear, clothing, board and pieces are retained. Empty accessory items remove only that slot. Choices must be server-validated and saved with field-only updates. Migration 0033 moves old face='glasses' into the new eyewear slot, preserving the rest of the loadout.

Original SVG art is generated by games/cosmetic_art.py and the cosmetic_art template tag. Identifiers are resolved through the server-owned catalog and the accessible label is escaped. No user SVG or markup is interpolated. Character heads share an eye line and jaw attachment. Humanized animals have distinct ears, muzzles and markings; wider dinosaur, crocodile, alien and robot craniums scale their headwear adapter around (80,40). Layer order: background, clothing/neck, head, hair, beard, eyewear, earrings, headwear. Hairstyle and headwear can both be selected; a hat naturally covers part of the hairstyle. Never deform the whole character to fit a hat.

The shop's equipped avatar uses a bust view to make clothing visible. The catalog and sidebar retain compact head portraits. Accessory catalog tiles show only the object, not the avatar. The 20 piece styles include four existing silhouette styles and sixteen additional color finishes of the Modern silhouette. These are explicitly finishes, not twenty distinct geometric models. Each set has twelve SVG assets, including promotions.

Board palettes preserve selection and legal-move overlays. Lava and marble use static decorative textures, with no animation or external textures. The compact shop keeps equipped previews sticky. Native CSRF-protected forms work without JavaScript. Enhanced saves refresh server-rendered previews and the sidebar avatar, preserve open categories and scroll, and report failed saves without changing equipment.

Avatar expansion: the avatar category now has 40 entries; other categories and their items are unchanged. Twenty additional original drawings live in cosmetic_art_more.py. Messi is a stylized fan illustration inspired by the player, not an official portrait or endorsement. Animal ears, muzzles, trunks and horns use the same attachment rig; wide heads get a headwear adapter. Existing selections remain valid.
