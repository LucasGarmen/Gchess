# Gchess ivory and walnut pieces

Original vector artwork created for Gchess, with a shared carved base, warm ivory and walnut colors, and brass details. No third-party piece artwork is included.

The SVG files are the editable originals. The 256 × 256 transparent PNG exports are used by the game, analyzer and training boards. Keep the square canvas and export proportions when editing; the board displays images with `object-fit: contain`.
